# CyberFi Releases

CyberFi’ın herkese açık Windows ve macOS dağıtım deposu.

- [Windows x64 — 0.0.117 önizlemesi](https://github.com/CyberfiTechh/CyberFi-Releases/releases/tag/v0.0.117)
- [macOS Intel (x64) — 0.0.117 DMG](https://github.com/CyberfiTechh/CyberFi-Releases/releases/download/macos-v0.0.117/CyberFi-0.0.117-x64.dmg)
- [macOS Apple Silicon (ARM64) — 0.0.117 DMG](https://github.com/CyberfiTechh/CyberFi-Releases/releases/download/macos-v0.0.117/CyberFi-0.0.117-arm64.dmg)
- Windows yayınları `v<sürüm>`, macOS yayınları `macos-v<sürüm>` etiketiyle aynı depoda ayrılır. Eski indirme bağlantıları korunur.
- Mac paketleri önizlemedir ve elle kurulur. Intel paketi Developer ID imzasızdır; ARM64 paketi ad-hoc imzalıdır. Apple noter onayı ve otomatik Mac güncellemesi yoktur.
- Mac kullanıcıları kendi işlemcilerine uygun DMG dosyasını indirip uygulamayı elle değiştirmelidir.
- Eski Windows sürümünüz güncellemeleri okuyamıyorsa 0.0.117 kurucusunu bir kez elle açın. Sonraki güncellemeleri **Ayarlar → Genel → Masaüstü uygulaması** bölümünden izleyebilirsiniz.
- Her sürümdeki `.sha256` dosyası kurulum dosyasının özetini içerir. `.update.json` dosyası uygulamanın imza doğrulaması içindir.
- Windows deneme paketleri yerel test sertifikasıyla imzalanır. Windows güven uyarısı gösterebilir.

CyberFi, MIT lisanslı [Happy Desktop](https://github.com/slopus/happy-desktop) projesini temel alır. [Özgün lisans ve telif bildirimi](LICENSE-Happy-Desktop.txt) kurulum paketinde de yer alır.
